# Diplom_1

Юнит-тесты класса `Burger` приложения Stellar Burgers.

Проект содержит 6 тестовых функций и 9 запусков с параметризацией. Каждый
тест проверяет один результат и заканчивается одним `assert`.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest
```

Проверка покрытия класса `Burger`:

```bash
pytest --cov=praktikum.burger --cov-report=term-missing --cov-report=html --cov-fail-under=100
```

HTML-отчёт создаётся локально в `htmlcov/index.html` и не добавляется в Git.

## Проверяемые методы

- установка булочки;
- добавление, удаление и перемещение ингредиента;
- расчёт стоимости бургера;
- формирование чека.
